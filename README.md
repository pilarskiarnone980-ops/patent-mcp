# Patent MCP Server

MCP-коннектор для ИИ-ассистента: поиск патентов РФ (Роспатент/ФИПС, Яндекс.Патенты с запасными источниками), патенты КФУ, справочник регламентов Роспатента.

Файлы: `main.py` — сервер; `regulations.md` — справочник (редактируемый); `requirements.txt`; `render.yaml`; `.python-version`.

## Инструменты
| Инструмент | Что делает | Нужен токен |
|---|---|---|
| `search_yandex_patents` | Поиск по ключевым словам. Яндекс.Патенты → Роспатент → Google Patents (RU) | нет (с токеном лучше) |
| `rospatent_search` | Поиск по Поисковой платформе Роспатента (семантический или языком запросов) | да |
| `rospatent_get_document` | Полный документ по ID (формула, описание) | да |
| `fips_get_document` | Карточка из открытых реестров ФИПС по номеру: статус, правообладатель, реферат, формула | нет |
| `search_kfu_patents` | Патенты с правообладателем КФУ, можно с темой | нет (с токеном лучше) |
| `get_patenting_guidelines` | Формула, описание, реферат, ST.26, пошлины, этапы, МСП, служебные изобретения | нет |

## Деплой на Render.com — пошагово

### 0. Что понадобится
- Аккаунт GitHub (бесплатно) — github.com → Sign up.
- Аккаунт Render — render.com → Get Started → «Sign in with GitHub» (так проще всего).
- (Желательно) токен API Поисковой платформы Роспатента: зарегистрируйтесь на searchplatform.rospatent.gov.ru, в личном кабинете найдите раздел доступа к API и получите токен (JWT — длинная строка). Без токена работают ФИПС-карточки, справочник и запасной поиск.

### 1. Загрузите файлы на GitHub (без командной строки)
1. На github.com нажмите «+» в правом верхнем углу → **New repository**.
2. Имя, например `patent-mcp`. Видимость — **Private** (секретов в коде нет, но так спокойнее). Нажмите **Create repository**.
3. На странице пустого репозитория нажмите ссылку **uploading an existing file**.
4. Перетащите в окно ВСЕ файлы проекта: `main.py`, `regulations.md`, `requirements.txt`, `render.yaml`, `.python-version`, `.gitignore`, `README.md`.
   - Файлы, начинающиеся с точки, в macOS скрыты: в Finder нажмите Cmd+Shift+. чтобы их увидеть. Если `.python-version` не загрузится — не страшно, версия Python задаётся ещё и в шаге 3.
5. Внизу нажмите **Commit changes**.

### 2. Придумайте секретный путь
Адрес сервера будет публичным. Чтобы его не нашли случайно, MCP будет отвечать только по «секретному» пути.
Придумайте строку из латинских букв и цифр, 16+ символов, например `mcp-k7q2v9x4m8p3z6w1`. Только буквы, цифры и дефис — без `/`, `+`, пробелов. Сохраните её.

### 3. Создайте сервис на Render
1. В панели Render: **New +** → **Web Service**.
2. Выберите репозиторий из GitHub (Render попросит доступ — разрешите для репозитория `patent-mcp`) → **Connect**.
3. Заполните форму:
   - **Name**: `patent-mcp` (из него получится адрес `https://patent-mcp.onrender.com`; если имя занято, Render добавит суффикс).
   - **Region**: Frankfurt (EU Central) — ближе к России.
   - **Branch**: `main`.
   - **Runtime / Language**: Python 3.
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn main:app --host 0.0.0.0 --port $PORT --proxy-headers --forwarded-allow-ips="*"`
   - **Instance Type**: **Free**.
4. В разделе **Environment Variables** добавьте (**Add Environment Variable**):
   - `PYTHON_VERSION` = `3.12.7`
   - `MCP_PATH` = ваша секретная строка из шага 2 (без слэшей)
   - `ROSPATENT_TOKEN` = токен Роспатента (если есть; можно добавить позже)
   - В **Advanced** → **Health Check Path**: `/healthz`
5. Нажмите **Create Web Service** (или **Deploy**). Откроется лог сборки. Через 2–5 минут появится строка о том, что сервис запущен (live).

Альтернатива шагу 3: **New + → Blueprint**, выбрать репозиторий — Render прочитает `render.yaml` и спросит только `MCP_PATH` и `ROSPATENT_TOKEN`.

### 4. Проверьте, что сервер жив
- Скопируйте адрес вверху страницы сервиса, например `https://patent-mcp.onrender.com`.
- Откройте в браузере `https://patent-mcp.onrender.com/healthz` — должно быть `{"status":"ok","rospatent_token":true,...}` (`false`, если токен не задан).

### 5. Итоговый URL коннектора
```
https://<имя-сервиса>.onrender.com/<MCP_PATH>
```
Пример: `https://patent-mcp.onrender.com/mcp-k7q2v9x4m8p3z6w1`

Эту ссылку вставляете в настройки ИИ-платформы как адрес пользовательского (custom) MCP-коннектора, без авторизации (OAuth не нужен). Открывать её в браузере бессмысленно: она отвечает только на MCP-запросы, в браузере будет ошибка — это нормально.

### 6. Как обновлять
- Изменили код или `regulations.md` → на GitHub откройте файл → значок карандаша → правка → **Commit changes**. Render сам пересоберёт сервис.
- Токен меняется в Render: сервис → **Environment** → правка → **Save Changes** (сервис перезапустится).

## Важные ограничения
- **Бесплатный Render «засыпает»** после ~15 минут без запросов; первый запрос после сна идёт 30–60 секунд, и ассистент может получить таймаут — просто повторите. Чтобы не засыпал, можно настроить бесплатный пинг `/healthz` каждые 10 минут (например, UptimeRobot).
- **Гео-блокировки.** Серверы Render находятся за рубежом, а сайты ФИПС/Роспатента нередко ограничивают зарубежные IP. Если `fips_get_document` / `rospatent_search` стабильно возвращают 403 или таймаут, а `/healthz` работает — перенесите тот же код на российский хостинг (например, Amvera или Timeweb Cloud: там тоже деплой из Git, команда запуска та же; условия бесплатных тарифов уточняйте).
- **Яндекс.Патенты** с лета 2025 года приостановлены (страница-заглушка), а поиск Яндекса блокирует серверы капчей. Инструмент пробует Яндекс и автоматически переходит на Роспатент и Google Patents; поле `source` в ответе показывает, какой источник сработал.
- Google Patents используется через неофициальный эндпоинт и может отвечать 429/503 с облачных IP.
- Справочник `regulations.md` — конспект на 01.10.2026; суммы пошлин сверяйте с калькулятором на rospatent.gov.ru.

## Локальный запуск и проверка (необязательно)
```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
MCP_PATH=mcp uvicorn main:app --port 8000              # PowerShell: $env:MCP_PATH="mcp"; uvicorn main:app --port 8000
npx @modelcontextprotocol/inspector                      # Transport: Streamable HTTP, URL: http://localhost:8000/mcp
```
